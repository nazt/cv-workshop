Technical Contributions

WiFiConnector

ESP8266/ESP32 Library · 3K+ GitHub Stars

Zero-configuration WiFi management library for Arduino ecosystem. Eliminates credential hardcoding with automatic AP fallback and web-based configuration portal.

C++ WiFiConnector.ino 
#include <WiFiConnector.h>

WiFiConnector wifi("MySSID", "password");

void setup() {
    wifi.init();
    wifi.on_connected([](WiFiConnector* w) {
        Serial.println("Connected!");
        Serial.println(WiFi.localIP());
    });
    wifi.connect();
}

void loop() {
    wifi.loop();
}

Impact: Reduced IoT deployment complexity by 60%. Adopted by industrial partners for smart agriculture and factory automation.

CMMC_NB-IoT

Cellular IoT Platform · Production Infrastructure

Enterprise-grade NB-IoT communication stack for remote sensor networks. Handles connection management, data serialization, and power optimization for battery-operated devices.

C++ sensor_node.cpp 
#include <CMMC_NB_IoT.h>

CMMC_NB_IoT nb("device_token");

void setup() {
    nb.init();
    nb.on_message_sent([](CMMC_NB_IoT* n) {
        Serial.println("Data transmitted");
        enterDeepSleep(3600); // 1hr sleep
    });
}

void loop() {
    float temperature = readSensor();
    nb.send(temperature);
}

Impact: Powers 200+ sensor nodes monitoring air quality, water levels, and agricultural metrics across Northern Thailand.

Civic Technology

FloodBoy Early Warning System

2019 - Present · Open Hardware

Autonomous flood monitoring system combining radar sensors, machine learning, and solar power. Deployed in flood-prone communities lacking infrastructure access. Real-time water level tracking with SMS/LINE alerts to residents.

Radar Sensor Array

Custom ultrasonic + mmWave radar fusion for accurate water level measurement under challenging environmental conditions (debris, vegetation, turbulence).

  • ±2cm accuracy up to 10m range
  • Temperature-compensated readings
  • Self-cleaning mechanical design

AI Prediction Model

TensorFlow Lite model running on ESP32 analyzing historical patterns, rainfall data, and upstream sensors. Provides 2-6 hour advance warning with 85% accuracy.

  • On-device inference (no cloud dependency)
  • Trained on 3 years of monsoon data
  • Adaptive learning from local conditions

Solar Power System

Off-grid operation with intelligent power management. 20W solar panel + 12Ah lithium battery providing 7-day autonomy during continuous cloudy conditions.

  • MPPT charge controller with battery protection
  • Dynamic duty cycling based on power budget
  • Remote battery monitoring and diagnostics

Impact: 12 units deployed protecting 2,000+ households. Average warning time improved from 30 minutes to 4 hours. Zero false negatives in 2 monsoon seasons. Hardware schematics and firmware released under MIT license.
